# Ipl-data-analysis

This is a data analysis of the IPL . The csv file is from Great Learning .
 I have practiced python data analysis libraries like Pandas and Matplotlib .

There are 18 columns and 756 rows in this dataset.

#Dataset Overview:  
🆔 id: Unique identifier for each match.  
🌦️ season: The season in which the match was played.  
🏙️ city: The city where the match took place.  
📅 date: The date of the match.  
🏏 team1: The name of the first team.  
🏏 team2: The name of the second team.  
🏆 toss_winner: The team that won the toss.  
🤔 toss_decision: Decision taken by the toss winner (bat or bowl).  
🏁 result: The result of the match.  
🔢 dl_applied: Indicates if the Duckworth-Lewis method was applied.  
🥇 winner: The team that won the match.  
🏃‍♂️ win_by_runs: Runs by which the match was won.  
🏏 win_by_wickets: Wickets by which the match was won.  
🌟 player_of_match: The player awarded for outstanding performance.  
🏟️ venue: The venue where the match was held.  
👨‍⚖️ umpire1: Name of the first umpire.  
👨‍⚖️ umpire2: Name of the second umpire.  
👨‍⚖️ umpire3: Name of the second umpire.  

#Tools Used:
Pandas: Used for data manipulation and analysis.  
Matplotlib: Used for data visualization.
